# Requisitos de la aplicación de reservas de salones de eventos

## Objetivo

Desarrollar una aplicación web que permita a los usuarios consultar la disponibilidad y reservar salones para eventos de forma rápida y sencilla.

## Usuarios

### Cliente

* Registrarse en la aplicación.
* Iniciar sesión.
* Consultar salones disponibles.
* Ver características y capacidad de cada salón.
* Realizar reservas.
* Consultar y cancelar sus reservas.

### Administrador

* Gestionar salones.
* Gestionar reservas.
* Gestionar usuarios.
* Consultar el calendario de ocupación.

## Funcionalidades principales

* Registro e inicio de sesión.
* Consulta de salones disponibles.
* Visualización de detalles de cada salón.
* Reserva de fechas disponibles.
* Cancelación de reservas.
* Gestión de salones y reservas por parte del administrador.

## Requisitos funcionales

RF1. El usuario podrá registrarse en la aplicación.

RF2. El usuario podrá iniciar sesión mediante usuario y contraseña.

RF3. El usuario podrá consultar los salones disponibles.

RF4. El usuario podrá visualizar la capacidad, ubicación y servicios de cada salón.

RF5. El usuario podrá seleccionar una fecha para realizar una reserva.

RF6. El sistema impedirá realizar reservas en fechas ya ocupadas.

RF7. El usuario podrá consultar sus reservas realizadas.

RF8. El usuario podrá cancelar una reserva.

RF9. El administrador podrá añadir, modificar y eliminar salones.

RF10. El administrador podrá gestionar todas las reservas del sistema.

## Requisitos no funcionales

RNF1. La aplicación deberá funcionar correctamente en ordenadores y dispositivos móviles.

RNF2. La interfaz deberá ser sencilla e intuitiva.

RNF3. Los datos de usuarios y reservas deberán almacenarse de forma segura.

RNF4. La aplicación deberá estar disponible las 24 horas del día.

RNF5. El tiempo de respuesta de las consultas deberá ser inferior a 3 segundos en condiciones normales.

# Historias de Usuario - Equipo del Cerro

## Historias de Usuario Generales
* Como visitante, quiero ver el listado de pistas y eventos deportivos disponibles, para elegir dónde reservar.
* Como visitante, quiero reservar un espacio del Castillo en una fecha y hora concretas, para organizar una visita privada.
* Como organizador, quiero reservar una Sala del Cerro, para celebrar una reunión o un acto.
* Como usuario, quiero consultar y cancelar mis reservas, para gestionar mis planes.
* Como administrador, quiero ver todas las reservas de los tres módulos en un único panel, para gestionarlas sin entrar en cada módulo por separado.

## Historias de Usuario Específicas (Equipo del Cerro)
* Como usuario, quiero consultar el listado de las salas del Cerro (como la sala de reuniones o el auditorio) para conocer los espacios disponibles.
* Como usuario, quiero acceder a la página de detalle de una sala del Cerro para ver su capacidad, equipamiento y descripción detallada.
